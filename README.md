# TaxiService_Itrun

Учебное консольное приложение на Python 3.11+ для управления службой такси.
Используется только стандартная библиотека. Устанавливать пакеты не нужно.

## Запуск

Откройте терминал в папке, где находится `main.py`:

```bash
python3 main.py
```

В Windows можно использовать `python main.py`.

## Возможности

- Регистрация, просмотр, поиск, изменение и удаление пассажиров и водителей.
- Уникальные ID внутри каждого списка и уникальные номера машин.
- Стандарт: 10 + 3 × км; комфорт: 20 + 5 × км, цены в сомони.
- Автоматический ID заказа, предварительная стоимость перед подтверждением.
- Создание, принятие, начало, завершение и отмена поездки.
- Проверка категории автомобиля: она должна точно совпадать с тарифом.
- Запрет нескольких активных заказов у одного водителя.
- Освобождение водителя после завершения или отмены принятого заказа.
- История, новые заказы и статистика; выручка только по завершённым поездкам.
- Запрет удаления пользователей с любыми связанными заказами, включая архивные.
- Запрет изменения автомобиля при активной поездке.
- Проверки имён, телефонов, ID, расстояния, цены и категории машины.
- Автосохранение после изменений через сервис и сохранение при выходе.
- Журнал успешных действий с заказами.

## Данные

При первом запуске создаётся `data/taxi_data.json` рядом с исходниками.
Журнал записывается в `data/actions.log`. Эти файлы не добавляются в Git.
Пустая папка данных не требует ручного создания.

При повреждении JSON или несогласованности связей запуск останавливается
с понятным сообщением. Исходный файл не перезаписывается. Сохраните его копию,
исправьте данные или переименуйте файл для запуска с пустым состоянием.
Не запускайте несколько экземпляров программы с одним файлом одновременно.
При ошибке записи изменения могут остаться в памяти: устраните проблему
с диском или правами и выберите «Сохранить» до закрытия программы.

## Тесты

Из той же папки:

```bash
python3 -m unittest discover -s tests -v
```

В комплекте 25 тестов: 15 обязательных сценариев ТЗ и дополнительные
проверки ошибок, JSON, логирования и консольного интерфейса.
Проверено в Python 3.12; отдельный запуск на Вашем Mac ещё требуется.

## ООП

`User` и `Tariff` — абстрактные классы. `Passenger` / `Driver` и два тарифа
показывают наследование. `calculate_price()` и `get_info()` — полиморфизм.
Водитель содержит объект `Car` — композиция. `_is_available` и `@property`
предоставляют управляемый доступ к занятости. `Validator` использует
`@staticmethod`, восстановление моделей — `@classmethod`.
Комментарии в коде расположены перед смысловыми блоками.

## Интерфейс сервиса

Ваши названия `assign_driver()` и `complete_trip()` сохранены. Названия
`accept_order()` и `complete_order()` из ТЗ — ссылки на те же реализации.
Тариф в заказе хранится как `standard` или `comfort`.

```python
service = TaxiService()  # Работа в памяти без файлов и логирования
order = service.create_order(passenger_id=1, distance=6, tariff=StandardTariff())
```

Сначала необходимо зарегистрировать пассажира. Для сохранения передайте
`TaxiService(data_path="data/taxi_data.json", log_path="data/actions.log")`.
Старый вызов `create_order(order_id, passenger_id, distance, tariff)` также
поддерживается с проверкой уникальности указанного ID.
Изменяйте состояние через сервис: прямые изменения полей моделей не вызывают
автосохранение и могут нарушить связи.

## Git

Для существующего репозитория скопируйте исходники из архива в папку проекта,
сохранив Вашу папку `.git`, затем выполните:

```bash
git status
git add main.py models.py tariffs.py services.py utils.py decorators.py tests README.md TZ.md DEMO.md .gitignore
git commit -m "feat: завершить консольный сервис такси с JSON, статистикой и тестами"
git push
```

Архив не содержит окружение `venv`, историю `.git` и настройки IDE.
Отправка в GitHub из этой среды не выполнялась.
